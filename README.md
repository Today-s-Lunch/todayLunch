# 오늘의 점심은

## 🍽️ 주요 기능

### 🔍 식당 검색
- 메뉴명/식당명으로 검색
- 음식 종류, 거리, 조리시간, 가격대, 대기시간별 필터링

### 📍 위치 기반 추천
- Google Maps API 활용 현재 위치 기반 가까운 식당 5개 추천

### 🎲 랜덤 추천
- 새로운 맛집 발견을 위한 랜덤 식당 추천

### 📋 식당 상세 정보
- 조리시간, 대기시간, 가격대, 별점, 리뷰
- 네이버 링크 연동

### ⭐ 리뷰/스크랩 기능
- 리뷰 작성, 수정, 삭제
- 맛집 스크랩 및 나만의 리스트 관리

### 📱 마이페이지
- 개인 정보 수정
- 스크랩한 식당 관리
- 작성한 리뷰 관리

### 🏫 학식 정보
- 순헌관, 명신관 학식 메뉴 제공

### 👤 회원 관리
- 학번 기반 회원가입/로그인
